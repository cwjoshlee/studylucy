# AI 학습실과 일일 스텝업 숙제 설계

## 목표

보호자가 AI 제공자·키·예산·문제 생성·보고서를 안전하게 관리하고, 수아가 국어와 수학의 `기초 → 현재 수준 → 도전` 숙제를 분명한 친구 역할과 태블릿 친화적인 이동 메뉴로 끝까지 풀 수 있게 한다.

## 범위

- 보호자 화면에 `AI 학습실` 최상위 메뉴를 추가한다.
- AI 학습실은 본문 상단에서 펼치는 트리 메뉴로 구성한다. 보호자 화면의 왼쪽 고정 메뉴는 사용하지 않는다.
- AI 설정, 문제 생성, 보호자 보고서를 기능별 하위 메뉴로 분리한다.
- 일일 국어·수학 숙제는 각각 기초, 현재 수준, 도전의 세 단계로 구성한다.
- 수학 기본 출제는 두 자리 수 덧셈·뺄셈, 받아올림·받아내림, 2~3개 식 혼합 계산을 우선한다.
- 국어에는 녹음과 독립적으로 동작하는 낱말·짧은 문장 받아쓰기를 추가한다.
- 버니·밀키·차나핑의 역할과 노출 위치를 분리한다.
- 수아 화면에 단일 보라색 플로팅 메뉴를 추가한다.

## 정보 구조

메뉴는 화면의 실제 가로·세로 사용 방식에 따라 전환한다. CSS 기준은 `최소 900 CSS px`이면서 `landscape`인 경우를 큰 가로 화면으로 본다. 이 기준은 모니터와 11·13인치 태블릿을 가로로 쓸 때에만 적용한다. 세로형 태블릿과 휴대폰은 화면 폭이 넓어도 세로형 흐름을 유지한다.

- 큰 가로 화면은 왼쪽에 고정 메뉴 레일을 두고, 현재 메뉴·AI 학습실 트리·기기 관리를 그 레일에 표시한다. 실제 숙제, 받아쓰기, 보호자 패널은 오른쪽의 넓은 본문에 표시한다. 문제 카드는 과도하게 넓어지지 않도록 읽기 쉬운 최대 폭을 가진다.
- 세로형 화면은 고정 레일을 숨기고 오른쪽 아래의 단일 보라색 플로팅 버튼으로 메뉴를 연다. 학생은 뒤로·오늘 학습·도움말·잠깐 쉬기를, 보호자는 최상위 보호자 메뉴와 기기 관리를 펼친다.
- 메뉴 전환은 같은 학습·보호자 상태를 유지한다. 회전하거나 화면 폭이 달라져도 입력 중인 답, 열린 AI 학습실 하위 메뉴, 선택한 보호자 패널을 잃지 않는다.

`AI 학습실`은 큰 가로 화면에서는 왼쪽 메뉴 레일 안의 펼침 트리로, 세로형 화면에서는 플로팅 메뉴에서 열리는 본문 상단 트리로 표시한다. 기기 관리는 계정 메뉴와 별도 진입점 모두에서 열 수 있다.

AI 학습실의 트리는 다음과 같다.

```text
AI 학습실
├─ AI 설정
│  ├─ 제공자·모델 선택
│  ├─ API 키 관리
│  └─ 월 예산·사용량
├─ 문제 생성
│  ├─ 수학 문제 배치
│  └─ 국어·받아쓰기 배치
└─ 보호자 보고서
   ├─ 오늘의 학습 요약
   └─ 주간 변화
```

AI 설정은 기본적으로 비활성화한다. API 키는 HTTPS 요청으로 한 번만 제출하고 NAS의 암호화 키로 암호화해 저장한다. 조회 응답에는 키 원문이나 일부 문자열을 포함하지 않고 저장 여부만 반환한다. 제공자와 모델 선택은 각 제공자의 키가 저장된 경우에만 해당 배치·보고서 실행에 사용한다.

## AI 문제 생성과 보고서

문제 배치 생성 화면은 과목, 단계, 목표 개수, 난이도, 자주 틀린 유형을 입력으로 받는다. 두 제공자가 선택되어 있으면 전체 개수를 반씩 나눠 생성한다. 각 제공자는 반대 제공자가 만든 문제를 감리한다. 형식·정답·학년 범위·난이도·중복·안전 기준을 통과하지 못한 항목은 발행 후보에서 제외한다.

생성 결과는 항상 초안이다. 보호자는 문제와 학습 문장을 미리보고 직접 추가·수정·삭제한 뒤에만 일일 숙제 또는 선택 학습으로 발행할 수 있다. AI 호출 실패, 감리 실패, 키 미설정, 월 예산 초과는 명확한 오류 상태로 표시하고 기존 발행 숙제나 진도는 변경하지 않는다.

보호자 보고서는 완료율, 단계별 정오답, 자주 틀린 유형, 도전 만점 여부를 기반으로 요약한다. AI 보고서는 선택 사항이며 실패하면 결정론적 로컬 요약을 표시한다.

## 일일 스텝업 숙제

일일 국어와 수학은 다음 순서를 강제한다.

```text
기초 완료 → 현재 수준 열림 → 현재 수준 완료 → 도전 열림 → 도전 시도 완료 → 해당 과목 완료
```

- 기초는 당일 핵심 개념을 짧게 확인한다.
- 현재 수준은 수아의 기본 숙제이며 이전 풀이·오답 경향을 반영한다.
- 도전은 한 단계 높은 응용 또는 혼합 계산이다.
- 도전은 정답이 아니어도 풀이와 함께 다음 문제 또는 완료로 진행한다. 정답 요구로 막히지 않는다.
- 도전 단계의 모든 문제를 맞히면 해당 과목의 일반 별과 별도로 보너스 별을 지급한다. 기본 보너스는 2별이며 보호자가 국어·수학별로 0~5별 범위에서 조정할 수 있다.
- 기초·현재 수준에서 자주 틀린 유형은 다음 일자의 해당 과목 기초 단계에 우선 반영한다.

수학의 기본 단계는 두 자리 수 덧셈·뺄셈으로 구성한다. 수학 난이도는 보호자가 과목별 `기초`, `현재 수준`, `도전` 값을 조정할 수 있고, 덧셈·뺄셈 중심을 유지한다. 곱셈은 기본 일일 문제에 섞지 않는다.

국어 받아쓰기는 낱말을 먼저, 짧은 문장을 나중에 제시한다. 듣기와 다시 듣기는 음성 합성으로 제공하고 큰 한글 입력칸에 갤럭시 탭의 한글 키보드를 연다. 받아쓰기는 녹음 상태·권한·전사에 의존하지 않는다.

## 친구 역할과 학생 이동

- 버니는 별빛 길 안내자다. 홈, 오늘의 목표, 보상, 도전 만점 축하에만 등장한다.
- 밀키는 공부 조수다. 수학 계산 단계와 받아쓰기 안에서 힌트, 다시 듣기, 풀이 재도전을 돕는다.
- 차나핑은 반응 코치다. 풀이 중 정오답·집중·휴식 상태에만 반응하고 버니·밀키의 안내 역할을 대신하지 않는다.

큰 가로 학생 화면은 왼쪽 메뉴 레일에 `뒤로`, `오늘 학습`, `도움말`, `잠깐 쉬기`를 항상 표시하고 실제 문제를 오른쪽에 둔다. 세로형 학생 화면의 오른쪽 아래 보라색 플로팅 버튼은 눌렀을 때 같은 네 동작을 펼친다. 각 항목은 터치 영역을 충분히 확보하고 키보드로도 열고 닫을 수 있어야 한다. 뒤로 가기와 오늘 학습 이동은 현재 답안을 잃지 않으며, 휴식은 무반응 판정을 일시 중지하는 기존 규칙을 따른다.

## 데이터와 호환성

기존 일일 계획과 학습 시도는 계속 읽을 수 있어야 한다. 새 단계·도전 시도·보너스 별은 별도 버전의 유효성 검사와 데이터베이스 마이그레이션으로 추가한다. AI 생성 초안, 감리 결과, 발행 상태는 일일 계획과 분리해서 저장한다. 실제 API 키, 원시 음성, 전체 음성 전사문은 저장하지 않는다.

## 검증 기준

- 모니터·가로형 11·13인치 태블릿은 왼쪽 메뉴 레일과 오른쪽 본문을, 세로형 태블릿·휴대폰은 플로팅 메뉴를 사용한다. 두 방식은 같은 메뉴와 현재 상태를 제공한다.
- 보호자 메뉴에서 AI 학습실과 기기 관리가 큰 가로 레일과 세로형 플로팅 메뉴 모두에서 보이고 조작 가능하다.
- AI 키 원문은 어떤 조회·오류·로그 응답에도 포함되지 않는다.
- 두 제공자 배치는 절반 생성과 상호 감리 결과를 초안으로만 남긴다.
- 기초·현재 수준·도전 잠금 순서와 도전 오답 완료 규칙이 국어와 수학에 적용된다.
- 도전 전부 정답일 때만 과목별 보너스 별이 한 번 지급된다.
- 수학 생성은 덧셈·뺄셈 중심과 선택한 난이도 범위를 지킨다.
- 받아쓰기는 낱말에서 짧은 문장으로 진행하고 음성 녹음 없이 완료할 수 있다.
- 버니·밀키·차나핑은 각각의 지정된 화면과 역할에서만 렌더링된다.
- 플로팅 메뉴는 뒤로, 오늘 학습, 도움말, 쉬기 동작을 제공하고 답안을 보존한다.
