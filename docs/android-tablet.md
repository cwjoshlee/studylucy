# Android 태블릿 사용 가이드

## 권장 환경

- 브라우저: Chrome for Android
- 접속 방식: Synology DDNS의 HTTPS 주소
- 사용 방식: Chrome 메뉴에서 "홈 화면에 추가" 또는 "앱 설치"
- 화면 방향: 가로 화면 기준 (13인치 Galaxy Tab), 세로/휴대전화는 반응형 보조 지원

## 왜 Chrome이 중요하나

현재 앱은 Chrome 브라우저 음성인식으로 아이가 읽은 문장을 전사합니다. 별도 LLM이나 앱 자체 외부 STT API를 쓰지 않으며, 음성 파일과 전체 전사문을 서버에 보내거나 저장하지 않습니다.

Chrome 음성인식은 브라우저 기능에 의존합니다. 기기, 브라우저 버전, 마이크 권한, 네트워크 상태에 따라 전사 결과가 없거나 부정확할 수 있으므로 수동 입력 판정 경로를 남겨두었습니다.

## 설치 후 테스트 순서

1. Android 태블릿의 Chrome에서 배포 URL을 엽니다.
2. Chrome 메뉴에서 홈 화면에 추가 또는 앱 설치를 선택합니다.
3. 홈 화면의 "수아의 공부방" 아이콘으로 앱을 엽니다.
4. 보호자가 현재 기기를 등록한 뒤 수아의 4자리 PIN으로 로그인합니다.
5. 오늘의 필수 학습 4개 중 하나를 눌러 학습 화면을 엽니다.
6. "읽기 시작"을 누르고 마이크 권한을 허용하거나 수동 입력 판정 경로를 사용합니다.
7. 아이가 문장을 끝까지 읽고 "읽기 완료"를 누릅니다.
8. 85점 이상이고 빠진 핵심 표현이 없을 때 `읽기 PASS`가 표시되는지 확인합니다.
9. 수학 문제에서는 지문과 문제를 읽기 PASS한 뒤 답 입력칸이 열리는지 확인합니다.
10. 답이 틀리면 다음 문제 버튼이 잠겨 있고 정답 뒤에만 열리는지 확인합니다.
11. 필수 완료 뒤 대시보드에서 완료 표시와 서버 확정 별 잔액이 갱신되는지 확인합니다.
12. 오프라인일 때 대기 별과 확정 잔액이 합쳐지지 않는지 확인합니다.
13. 다음 날 다시 열었을 때 새 날짜의 서버 일일 계획이 표시되는지 확인합니다.

실기기 인수에서는 Galaxy Tab을 가로로 두고 CSS viewport를 기록합니다. 핵심 버튼·입력칸의 실제 터치 영역 최솟값이 가로와 세로 모두 48px 이상인지 측정하고, 외부 키보드의 Tab/Shift+Tab 이동 순서와 `:focus-visible` 표시를 화면 캡처 또는 측정표로 남깁니다.

## 운영 팁

- 아이가 쓰는 기기에서는 Chrome을 기본 브라우저로 쓰는 편이 좋습니다.
- 첫 사용 전 태블릿 볼륨과 마이크 권한을 확인합니다.
- Chrome 음성인식이 중간에 조용해져도 앱이 다시 듣기를 시도합니다. 아이가 다 읽은 뒤에는 꼭 "읽기 완료"를 눌러 채점합니다.
- 읽기 PASS는 85점 이상과 핵심 표현 누락 없음이 함께 필요합니다.
- 한글 단락은 읽기 PASS, 수학 문제는 읽기 PASS와 수학 답 PASS가 모두 되어야 다음 문제로 갈 수 있습니다.
- 문제 순서, 진도와 별은 서버가 날짜별로 관리하므로 여러 등록 기기에서 같은 확정 상태가 보입니다.
- 음성 판정 점수보다 "어떤 표현을 다시 읽었는지"를 더 중요하게 봅니다.
- Chrome 전사가 이상하면 아이를 다시 평가하지 말고, 수동 입력으로 확인합니다.
- 이 화면은 진단이 아니라 읽기 연습 기록용입니다.
