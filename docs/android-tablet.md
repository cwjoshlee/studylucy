# Android 태블릿 사용 가이드

## 권장 환경

- 브라우저: Chrome for Android
- 접속 방식: Cloudflare Pages, GitHub Pages, 또는 NAS의 HTTPS 주소
- 사용 방식: Chrome 메뉴에서 "홈 화면에 추가" 또는 "앱 설치"
- 화면 방향: 세로와 가로 모두 가능

## 왜 Chrome이 중요하나

현재 프로토타입은 Chrome 브라우저 음성인식으로 아이가 읽은 문장을 전사합니다. 별도 LLM이나 외부 STT API를 쓰지 않으므로 앱 운영 비용은 들지 않습니다.

Chrome 음성인식은 브라우저 기능에 의존합니다. 기기, 브라우저 버전, 마이크 권한, 네트워크 상태에 따라 전사 결과가 없거나 부정확할 수 있으므로 수동 입력 판정 경로를 남겨두었습니다.

## 설치 후 테스트 순서

1. Android 태블릿의 Chrome에서 배포 URL을 엽니다.
2. Chrome 메뉴에서 홈 화면에 추가 또는 앱 설치를 선택합니다.
3. 홈 화면의 "수아 학습" 아이콘으로 앱을 엽니다.
4. "읽기 시작"을 누르고 마이크 권한을 허용합니다.
5. 아이가 문장을 끝까지 읽습니다. 최대 2분 동안 들을 수 있고, 다 읽으면 "읽기 완료"를 누릅니다.
6. 들은 문장과 붉은 굵은 글씨로 표시된 다시 읽을 부분을 확인합니다.
7. 85점 이상이고 빠진 핵심 표현이 없을 때 `읽기 PASS`가 표시되는지 확인합니다.
8. 수학 문제에서는 지문과 문제를 읽기 PASS한 뒤 답 입력칸이 열리는지 확인합니다.
9. 답을 입력하고 `PASS` 또는 `FAIL` 결과를 확인합니다.
10. `FAIL` 상태에서는 다음 문제 버튼이 잠겨 있는지 확인합니다.
11. "듣기" 버튼의 한국어 음성이 자연스러운지 확인합니다.
12. 수학 읽기에서 답 입력 키보드가 숫자로 뜨는지 확인합니다.

## 운영 팁

- 아이가 쓰는 기기에서는 Chrome을 기본 브라우저로 쓰는 편이 좋습니다.
- 첫 사용 전 태블릿 볼륨과 마이크 권한을 확인합니다.
- Chrome 음성인식이 중간에 조용해져도 앱이 다시 듣기를 시도합니다. 아이가 다 읽은 뒤에는 꼭 "읽기 완료"를 눌러 채점합니다.
- 읽기 PASS는 85점 이상과 핵심 표현 누락 없음이 함께 필요합니다.
- 한글 단락은 읽기 PASS, 수학 문제는 읽기 PASS와 수학 답 PASS가 모두 되어야 다음 문제로 갈 수 있습니다.
- 음성 판정 점수보다 "어떤 표현을 다시 읽었는지"를 더 중요하게 봅니다.
- Chrome 전사가 이상하면 아이를 다시 평가하지 말고, 수동 입력으로 확인합니다.
- 이 화면은 진단이 아니라 읽기 연습 기록용입니다.
