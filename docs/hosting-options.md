# 호스팅 결정 기록

## 현재 운영 경로

현재 승인된 운영 경로는 Synology NAS의 Container Manager다.

- Node 22 단일 앱이 React PWA, Fastify API와 예약 작업을 제공한다.
- SQLite와 백업은 NAS의 `/data` 볼륨에 유지한다.
- Synology DDNS와 Let's Encrypt 인증서를 사용한다.
- DSM 리버스 프록시는 HTTPS 443을 호스트 전용 `127.0.0.1:8787`로 전달한다.
- 공유기에는 TCP 443만 전달하고 DSM 5001과 앱 8787은 외부에 열지 않는다.
- CGNAT이면 배포를 중단하고 별도 터널을 임의로 추가하지 않는다.

구체적인 운영 절차는 [Synology 운영 배포 절차](../ops/synology/README.md)를 따른다.

## 과거 선택지

Cloudflare Pages와 GitHub Pages는 초기 정적 프로토타입을 시험하기 위한 후보였다. 정적 호스팅은 보호자 인증, 여러 기기 동기화, 서버 권위 별 원장, 유지보수와 검증된 백업을 제공할 수 없어 현재 애플리케이션의 운영 대상이 아니다. Cloudflare 관련 설정과 정적 프로토타입은 20개 콘텐츠와 아이콘의 이관 일치를 검증한 뒤 제거했다.

WordPress.com 무료 플랜과 Synology Web Station 정적 호스팅도 같은 이유로 현재 운영 경로가 아니다. 이 기록은 초기 기술 선택의 역사만 보존하며 재배포 지침으로 사용하지 않는다.

## 변경 승인 기준

Synology 이외 경로로 바꾸려면 다음을 다시 검토하고 사용자 승인을 받는다.

1. 가족 인증과 신뢰 기기 쿠키의 보안 속성
2. SQLite 또는 대체 데이터 저장소의 일관성·백업·복원
3. 오프라인 이벤트의 멱등 동기화
4. 외부 공개 포트와 TLS 종료 지점
5. PIN, 토큰, 오디오와 전체 전사문 비저장 경계
