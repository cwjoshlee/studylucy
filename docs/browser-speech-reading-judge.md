# Chrome 음성인식 기반 읽기 판정 설계

## 목표

아이가 화면의 한글 동화 단락을 직접 읽으면, Android Chrome의 브라우저 음성인식이 전사하고 앱이 기준 문장과 로컬 비교합니다. 목적은 진단이 아니라 정확하게 읽는 연습과 보호자의 관찰입니다. 계산 문제는 이 읽기 판정 흐름에 들어가지 않습니다.

## 기본 흐름

1. 아이가 `읽기 시작`을 누른다.
2. Chrome 마이크 권한을 허용한다.
3. 듣는 동안 빨간 상태 표시와 경과 시간, 항상 보이는 `읽기 멈추기`를 제공한다.
4. 첫 음성 결과 뒤 3초 동안 새 결과가 없으면 인식을 마친다. 결과가 전혀 없으면 15초에 직접 입력 안내를 표시하고, 전체 세션은 최대 45초에 끝낸다.
5. 아이가 먼저 마치고 싶으면 `읽기 멈추기`를 누른다.
6. 앱이 전사 텍스트와 기준 문장을 브라우저 안에서 비교한다.
7. 한글 읽기는 다시 읽을 표현을 붉은 굵은 글씨로 표시한다.
8. 읽기 점수가 85점 이상이고 빠진 핵심 표현이 없어야 `읽기 PASS`로 처리하며, 저장 결과가 확정되면 1.5초 뒤 다음 문제로 자동 이동한다.
9. 날짜별 문제 순서와 완료 결과는 서버 권위의 일일 계획·풀이 기록으로 저장한다.
10. 음성 파일과 전체 전사문은 저장하거나 앱 서버로 보내지 않고 점수와 누락 표현만 저장한다.

## 판정 경계

- LLM을 사용하지 않는다.
- 외부 STT API를 사용하지 않는다.
- 음성 판정 자체에는 OpenAI API 키나 별도 STT 서버 환경 변수가 필요하지 않다.
- 학습 앱은 Synology NAS의 Node 22 컨테이너에서 운영한다.

Chrome의 Web Speech API는 브라우저 기능에 의존하므로 기기, 브라우저 버전, 네트워크, 권한 설정에 따라 결과가 다를 수 있습니다. 결과가 없을 때는 수동 입력 판정 경로를 사용합니다.

첫 결과 뒤 3초 무음 종료, 무결과 15초 안내, 45초 전체 상한은 앱이 명시적으로 관리합니다. 명시적 중지·무음·상한에 도달하지 않았는데 브라우저 `onend` 또는 재시도 가능한 오류가 먼저 오면 지금까지의 결과를 합치고, 듣는 중 상태와 빨간 표시를 유지한 채 250ms 뒤 인식 엔진을 다시 시작합니다. 명시적 중지·무음·상한은 마무리 뒤 한 번만 판정하고, 권한 거부·비지원·엔진 시작 실패는 재시작하지 않고 준비 상태와 직접 입력 경로로 전환합니다.

## 판정 기준

- `읽기 PASS`: 85점 이상이고 핵심 표현을 하나도 빠뜨리지 않음.
- `읽기 FAIL`: 85점 미만이거나 핵심 표현을 하나 이상 빠뜨림.
- `거의 됐어요`: FAIL이지만 다시 읽을 부분이 적어 조금만 고치면 PASS에 가까움.

## 표시 방식

- 들은 문장: Chrome이 전사한 텍스트를 그대로 표시한다.
- 다시 읽을 부분: 기준 문장 안에서 빠졌거나 다르게 인식된 핵심 표현을 붉은 굵은 글씨로 표시한다.
- 다시 볼 것: 보호자 패널에 최근 어려웠던 표현을 누적한다.
- 계산 문제: 읽기 통과를 요구하지 않고 음성 인식·녹음·수동 전사 입력 없이 바로 큰 숫자 키패드를 연다. 0~9·지우기·답 확인으로 최대 두 자리 답을 입력한다.
- 다음 문제: 한글 단락은 저장된 읽기 PASS 뒤 1.5초 후 자동 이동하고, 계산 문제는 서버가 정답을 확인해야 열린다.
- 오늘의 문제: 같은 날짜에는 같은 문제 순서가 유지되고, 날짜가 바뀌면 순서와 진도가 새로 시작된다.

## 계산 오프라인 권위

- 호출자가 검증한 네트워크 `TypeError 또는 5xx` 경계에서 저장 요청을 오프라인 큐에 넣은 경우에만, 로컬에서 맞은 계산은 `provisional` 완료와 `동기화 대기`로 다음 문제를 잠정 해제할 수 있다.
- 이 잠정 상태는 서버 영수증이 아니다. 서버 확인 전에는 별을 확정하거나 확정 잔액에 더하지 않는다.
- 직접 요청의 `401·기기·계획 권한 거부`는 큐에 넣지 않고 현재 학습을 닫으며, API 권위 경계가 로컬 계획·별·세션 권위를 지우거나 기기 조치 필요 상태로 잠근다.
- 나중의 동기화에서 `terminal batch 거부`가 오면 해당 행을 비밀 없는 거절 기록으로 옮기고 provisional 완료를 제거한다. 401이나 기기 거부라면 큐를 보존한 채 권위를 잠그고 새 PIN 인증 또는 기기 복구 전까지 읽기·쓰기를 막는다.

## 개인정보 원칙

- 음성 파일을 저장하지 않는다.
- 전사와 채점은 브라우저 안에서 처리한다.
- 전체 전사문은 브라우저 메모리에서 판정할 때만 사용하고 서버에는 점수, 누락 표현, 답과 소요 시간만 보낸다.
- 확정 학습 진행과 별 원장은 NAS의 SQLite에 저장하고, 오프라인 전송 대기 항목만 브라우저 IndexedDB에 둔다.
- 학교, 주소, 전화번호 같은 정보는 입력하지 않는다.
- 이 화면은 난독증 진단 도구가 아니라 읽기 연습 도구로 사용한다.

## MVP 이후 확장

- 자주 틀리는 받침 또는 단어 유형 기록.
- 수학 문장 유형별 기록: 덧셈, 뺄셈, 비교.
- 매주 다시 읽기 목록 자동 생성.
- NAS에서 로컬 Whisper 같은 무료 자체 전사 서버를 운영하는 선택지.
