# Chrome 음성인식 기반 읽기 판정 설계

## 목표

아이가 화면의 한글 동화 단락 또는 수학 문제 지문을 직접 읽으면, Android Chrome의 브라우저 음성인식이 전사하고 앱이 기준 문장과 로컬 비교합니다. 목적은 진단이 아니라 정확하게 읽는 연습과 보호자의 관찰입니다.

## 기본 흐름

1. 아이가 `읽기 시작`을 누른다.
2. Chrome 마이크 권한을 허용한다.
3. Chrome 브라우저 음성인식이 최대 1분 동안 한국어 음성을 텍스트로 전사한다.
4. 아이가 다 읽으면 `읽기 완료`를 누른다.
5. 앱이 전사 텍스트와 기준 문장을 브라우저 안에서 비교한다.
6. 한글 읽기는 다시 읽을 표현을 붉은 굵은 글씨로 표시한다.
7. 읽기 점수가 85점 이상이고 빠진 핵심 표현이 없어야 `읽기 PASS`로 처리한다.
8. 수학 문제는 지문과 문제를 `읽기 PASS`한 뒤에만 답 입력칸을 연다.
9. 수학 답은 `PASS` 또는 `FAIL`로 표시한다.
10. `FAIL` 상태에서는 다음 문제 버튼을 잠근다.
11. 날짜별로 오늘의 문제 순서를 만들고 당일 진도만 저장한다.
12. 음성 파일은 저장하지 않고 서버로 보내지 않는다.

## 비용 원칙

- LLM을 사용하지 않는다.
- 외부 STT API를 사용하지 않는다.
- OpenAI API 키나 서버 환경 변수가 필요하지 않다.
- 정적 호스팅만으로 운영한다.

Chrome의 Web Speech API는 브라우저 기능에 의존하므로 기기, 브라우저 버전, 네트워크, 권한 설정에 따라 결과가 다를 수 있습니다. 결과가 없을 때는 수동 입력 판정 경로를 사용합니다.

음성인식이 조용한 구간에서 자동으로 끝나는 경우가 있어, 앱은 제한 시간 안에서 다시 듣기를 시도합니다. 채점은 자동 종료가 아니라 아이가 `읽기 완료`를 누르거나 1분 제한이 끝났을 때 실행합니다.

## 판정 기준

- `읽기 PASS`: 85점 이상이고 핵심 표현을 하나도 빠뜨리지 않음.
- `읽기 FAIL`: 85점 미만이거나 핵심 표현을 하나 이상 빠뜨림.
- `거의 됐어요`: FAIL이지만 다시 읽을 부분이 적어 조금만 고치면 PASS에 가까움.

## 표시 방식

- 들은 문장: Chrome이 전사한 텍스트를 그대로 표시한다.
- 다시 읽을 부분: 기준 문장 안에서 빠졌거나 다르게 인식된 핵심 표현을 붉은 굵은 글씨로 표시한다.
- 다시 볼 것: 보호자 패널에 최근 어려웠던 표현을 누적한다.
- 수학 답: 읽기 PASS 전에는 입력칸을 잠그고, 읽기 PASS 뒤 정답이면 `PASS`, 오답이나 미입력이면 `FAIL`로 표시한다.
- 다음 문제: 한글 단락은 읽기 PASS 뒤에만 열고, 수학 문제는 읽기 PASS와 수학 답 PASS가 모두 필요하다.
- 오늘의 문제: 같은 날짜에는 같은 문제 순서가 유지되고, 날짜가 바뀌면 순서와 진도가 새로 시작된다.

## 개인정보 원칙

- 음성 파일을 저장하지 않는다.
- 전사와 채점은 브라우저 안에서 처리한다.
- 학습 진행 기록은 브라우저 로컬 저장소에만 둔다.
- 학교, 주소, 전화번호 같은 정보는 입력하지 않는다.
- 이 화면은 난독증 진단 도구가 아니라 읽기 연습 도구로 사용한다.

## MVP 이후 확장

- 자주 틀리는 받침 또는 단어 유형 기록.
- 수학 문장 유형별 기록: 덧셈, 뺄셈, 비교.
- 매주 다시 읽기 목록 자동 생성.
- NAS에서 로컬 Whisper 같은 무료 자체 전사 서버를 운영하는 선택지.
