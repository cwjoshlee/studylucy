# Chrome 음성인식 기반 읽기 판정 설계

## 목표

아이가 화면의 한글 동화 단락 또는 수학 문제 지문을 직접 읽으면, Android Chrome의 브라우저 음성인식이 전사하고 앱이 기준 문장과 로컬 비교합니다. 목적은 진단이 아니라 정확하게 읽는 연습과 보호자의 관찰입니다.

## 기본 흐름

1. 아이가 `읽기 시작`을 누른다.
2. Chrome 마이크 권한을 허용한다.
3. Chrome 브라우저 음성인식이 한국어 음성을 텍스트로 전사한다.
4. 앱이 전사 텍스트와 기준 문장을 브라우저 안에서 비교한다.
5. 한글 읽기는 다시 읽을 표현을 붉은 굵은 글씨로 표시한다.
6. 수학 문제는 읽기와 별도로 답을 입력하고 `PASS` 또는 `FAIL`로 표시한다.
7. 음성 파일은 저장하지 않고 서버로 보내지 않는다.

## 비용 원칙

- LLM을 사용하지 않는다.
- 외부 STT API를 사용하지 않는다.
- OpenAI API 키나 서버 환경 변수가 필요하지 않다.
- 정적 호스팅만으로 운영한다.

Chrome의 Web Speech API는 브라우저 기능에 의존하므로 기기, 브라우저 버전, 네트워크, 권한 설정에 따라 결과가 다를 수 있습니다. 결과가 없을 때는 수동 입력 판정 경로를 사용합니다.

## 판정 기준

- `아주 좋아요`: 핵심 단어를 모두 읽고 전사 문장도 기준 문장과 매우 가까움.
- `거의 됐어요`: 한두 표현만 빠졌거나 전사 차이가 작음.
- `한 번 더`: 여러 핵심 표현을 빠뜨렸거나 전사 문장이 기준 문장과 많이 다름.

## 표시 방식

- 들은 문장: Chrome이 전사한 텍스트를 그대로 표시한다.
- 다시 읽을 부분: 기준 문장 안에서 빠졌거나 다르게 인식된 핵심 표현을 붉은 굵은 글씨로 표시한다.
- 다시 볼 것: 보호자 패널에 최근 어려웠던 표현을 누적한다.
- 수학 답: 정답이면 `PASS`, 오답이나 미입력이면 `FAIL`로 표시한다.

## 개인정보 원칙

- 음성 파일을 저장하지 않는다.
- 전사와 채점은 브라우저 안에서 처리한다.
- 학습 진행 기록은 브라우저 로컬 저장소에만 둔다.
- 학교, 주소, 전화번호 같은 정보는 입력하지 않는다.
- 이 화면은 난독증 진단 도구가 아니라 읽기 연습 도구로 사용한다.

## MVP 이후 확장

- 자주 틀리는 받침 또는 단어 유형 기록.
- 수학 문장 유형별 기록: 덧셈, 뺄셈, 비교.
- 매주 다시 읽기 목록 자동 생성.
- NAS에서 로컬 Whisper 같은 무료 자체 전사 서버를 운영하는 선택지.
