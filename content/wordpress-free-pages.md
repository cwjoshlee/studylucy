# 수아의 오늘 학습

한글을 또박또박 읽고, 수학 문장도 스스로 읽어보자.

## 오늘의 순서

1. 한글 낱말 5개 읽기
2. 짧은 문장 3개 읽기
3. 수학 이야기 문제 3개 읽기
4. 어려웠던 글자 1개 다시 읽기

## 오늘의 약속

- 빨리 읽지 않아도 괜찮아.
- 한 글자씩 정확하게 읽어보자.
- 모르면 멈추고 다시 보면 돼.

## 바로 가기

- 한글 읽기
- 수학 읽기
- 보호자 기록

# 페이지 3. 수학 읽기

# 수학 읽기

수학 문제도 먼저 문장을 정확하게 읽는 연습을 해요.

## 1단계. 수 읽기

- 사과가 3개 있어요.
- 연필이 5자루 있어요.
- 책상 위에 공이 7개 있어요.
- 딸기가 10개 있어요.

## 2단계. 덧셈 문장

- 수아는 사과 2개를 가지고 있어요. 엄마가 사과 1개를 더 주었어요. 모두 몇 개일까요?
- 연필 4자루가 있어요. 연필 2자루를 더 놓았어요. 모두 몇 자루일까요?
- 노란 블록 3개와 파란 블록 3개가 있어요. 모두 몇 개일까요?

## 3단계. 뺄셈 문장

- 쿠키가 5개 있어요. 수아가 2개를 먹었어요. 몇 개가 남았을까요?
- 공이 8개 있어요. 친구가 3개를 가져갔어요. 몇 개가 남았을까요?
- 꽃이 6송이 있어요. 1송이를 선물했어요. 몇 송이가 남았을까요?

## 4단계. 비교 문장

- 6은 4보다 커요.
- 3은 8보다 작아요.
- 5와 5는 같아요.

# 페이지 4. 보호자 기록

# 보호자 기록

## 오늘의 관찰

| 날짜 | 읽은 시간 | 잘 읽은 문장 | 어려웠던 부분 | 다음에 다시 볼 것 |
|---|---:|---|---|---|
|  |  |  |  |  |

## 관찰할 점

- 글자를 건너뛰는지
- 비슷한 글자를 바꿔 읽는지
- 받침을 빼고 읽는지
- 수학 문장을 끝까지 읽기 전에 계산부터 하려는지
- 다시 읽으면 스스로 고치는지

## 말해주기 좋은 피드백

- 방금은 천천히 보니까 더 정확했어.
- 어려운 글자를 찾은 것도 좋은 공부야.
- 한 번 더 읽으면 더 잘 들릴 것 같아.
- 답보다 문장을 읽은 게 먼저야.
